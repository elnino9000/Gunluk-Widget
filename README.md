# Günlük Widget

Android ana ekran widget'ı: gün ışığı yayı (güneş/ay), gece-gündüz renkleri, büyük saat ve tarih, hava durumu ve günün önemli hava olayları (yağmur, kar, sis...) küçük saatleriyle zaman çizelgesinde.

- APK her `push`ta GitHub Actions ile derlenir; **Releases → son-surum** sayfasından indirilir.
- Hava ve gün doğumu/batımı: Open-Meteo (ücretsiz, anahtar gerekmez).

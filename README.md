# Günlük Widget

Android ana ekran widget'ı: gün ışığı yayı (güneş/ay), gece-gündüz renkleri, saat, küçük hava bilgisi ve AA / TRT Haber / BBC Türkçe'den tek satır haber başlığı.

- APK her `push`ta GitHub Actions ile derlenir; **Releases → son-surum** sayfasından indirilir.
- Hava ve gün doğumu/batımı: Open-Meteo (ücretsiz, anahtar gerekmez).
- Haber: yalnızca ajans RSS başlıkları; "şok / izle / !" gibi tıklama tuzağı başlıklar elenir.
